Built for architecture, not just triangles

Kit-bashed buildings are the worst case for naive decimation: hundreds of disconnected sheets, thin trims, door and window openings. ComplexLODs was designed for exactly that.

Exterior bounds never move

Vertices on the 2D convex hull of 14 orthographic viewing projections are locked for the entire run — the silhouette from every angle is preserved by construction, not by luck.

Interior release ladder

When the heap stalls above the target, interior detail is released in depth-gated stages: feature-chain corners, then free interior movement, then interior openings. Outer bounds stay locked at every stage.

Openings stay open

Boundary loops for doors, windows and entrances are protected by topology guards; interior loops may only dissolve at the deepest targets — and only if they share no silhouette vertex.

Honest reporting

Every level reports target vs. actual triangles, release stage, and whether identical geometry was shared. A level that can't reach its budget without damage says so — nothing is faked.

Whole-hierarchy LODs

Point at a prefab root and every child renderer gets LODs; tiny pieces (≤256 tris) reuse the source mesh directly, and one LODGroup is configured automatically.

Texture LODs included

Materials are downscaled alongside geometry so distant LODs save texture memory too — all inside Unity, no external tools, no third-party code.

Frequently asked questions

What investors, partners and technical evaluators usually ask first.

What is ComplexLODs?

ComplexLODs is a level-of-detail (LOD) generator for Unity built on its own simplification stack — no third-party code. It decimates meshes with probabilistic quadric error metrics while locking exterior bounds, protecting openings and feature curves, and reporting honestly when a target can't be reached without damage.

Which Unity versions and render pipelines are supported?

The tool targets Unity 6000+ with the Universal Render Pipeline (URP) and runs entirely inside the Unity Editor via Window → ComplexLODs or the MeshRenderer / LODGroup context menus.

How is ComplexLODs different from a standard mesh decimator?

Standard decimators minimize geometric error but happily round off silhouettes and weld door and window openings shut. ComplexLODs locks every vertex on the 2D convex hull of 14 viewing projections, guards boundary-loop topology, only lets feature-curve vertices collapse along their chain, and releases interior detail in depth-gated stages — so LODs stay recognizable at distance.

Does the web demo upload my mesh to a server?

Yes — generation runs fully server-side so the algorithm is never exposed. Uploads and generated files are stored temporarily only: every job auto-deletes after 30 minutes. Nothing is logged or retained beyond that.

What input formats are supported?

Inside Unity the tool works on MeshRenderer hierarchies and prefabs directly, fills LODGroups, and can generate downscaled texture variants per level. The browser demo accepts .obj, .fbx, .stl, .glb/.gltf and .ply; generated levels download as .obj.

How are LOD levels configured?

Three presets mirror typical pipelines: Performance (3 levels, ×2.5 reduction), Balanced (4 levels, ×2.0) and Quality (6 levels, ×1.6). Every level is decimated from the LOD0 source — never chained — so errors don't accumulate, and byte-identical levels share one mesh asset.

What happens when a triangle target can't be reached?

The simplifier stops at the preservation floor instead of shredding the model. Each level reports target vs. actual triangles, release stage and boundary-loop counts — a level that can't reach its budget without damage says so.
